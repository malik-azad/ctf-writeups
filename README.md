## 🧭 Approach

A few principles run through everything in this repo:

- **Map before you attack.** Understand the whole surface before choosing a technique.
- **Cheapest useful move first.** Escalate effort only when the evidence says you must.
- **Read output for decisions, not just data.** Every scan line should either open an option or close one.
- **Verify before you trust.** Confirm findings on the target — don't inherit them from someone else's answer key.
- **Document as you go.** Notes, exact locations, and dead ends are what make a report possible later.

## ⚖️ Scope & Ethics

These writeups document **publicly available CTF rooms and deliberately vulnerable lab environments** designed for security education. They exist so others can learn offensive-security fundamentals safely and legally.

The techniques covered — service enumeration, OSINT, credential analysis, and Windows permission review — are standard professional skills. **Always practise only against systems you own or have explicit written authorisation to test.**
